# OfferLab｜实习投递决策助手

OfferLab 是一个面向实习求职者的本地 Web MVP，用于记录岗位阶段、比较投递渠道与简历版本的历史转化，并集中处理待跟进事项。

[在线体验](https://offerlab-internship-tracker.vercel.app)（数据仅保存在当前浏览器）

项目不把“小样本下某个渠道转化率更高”包装成确定结论，也不自动投递、不抓取招聘网站、不生成虚假简历经历。

## 核心功能

- 管理公司、岗位、方向、城市、渠道、简历版本和投递阶段
- 记录首次回复、计划跟进、JD 链接和下一步行动
- 展示投递量、回复率、面试转化率和到期待跟进数
- 按投递渠道和简历版本比较回复率、面试率
- 使用“JD 要求—简历证据矩阵”逐条关联真实项目或经历
- 将要求标记为“有证据 / 需补强 / 无证据”，按公开权重自动计算覆盖度
- 搜索并筛选投递记录
- 导出带 UTF-8 BOM 的 CSV，便于使用 Excel 打开
- 使用带版本号的 `localStorage` 结构保存数据，不上传用户信息
- 提供明确标注的匿名虚构演示数据

## 统计口径

- “准备投递”不进入回复率和面试率的分母。
- 回复率 = 填写首次回复日期的岗位数 / 已完成投递的岗位数。
- 面试率 = 当前阶段为“面试”或“Offer”的岗位数 / 已完成投递的岗位数。
- 证据覆盖度 =（有证据项 × 1 + 需补强项 × 0.5）/ 已记录要求数；无证据项权重为 0。
- 待跟进 = 跟进日期不晚于今天，并且尚未进入 Offer、已拒绝或已结束状态的岗位笔数。
- 渠道和简历版本之间的转化差异是描述性结果；样本量小、岗位结构不同，不能直接解释为因果。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

访问终端中显示的本地地址。构建与测试：

```bash
npm run build
npm test -- --run
```

## 技术实现

- React 19 + TypeScript + Vite
- SCSS 响应式界面
- 浏览器 `localStorage` 本地持久化
- Vitest 覆盖核心指标口径
- 无后端、无登录、无外部 API，便于快速部署为静态站点

## 能力边界

- 数据仅保存在当前浏览器，清除浏览器存储后无法恢复；请定期导出 CSV。
- 证据状态仍由用户判断，覆盖度只反映已记录要求的证据完整性，不代表 ATS 分数或录用概率。
- 当前不支持多设备同步、账号权限、自动提醒或招聘平台数据接入。
- 演示公司、岗位和结果均为虚构内容，不代表真实投递或录用经历。
